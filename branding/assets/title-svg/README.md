# Figma Sound title SVG kit

These are transparent, font-independent Didot Bold outlines with the reinforced stroke treatment used by the deck.

- `figma-word.svg` keeps FIGMA together on one line.
- `figma-f.svg` through `figma-a.svg` provide individual FIGMA glyphs.
- `sound-s.svg` through `sound-d.svg` provide individual SOUND glyphs for staggered placement.
- FIGMA fill: `#123C45`.
- SOUND fill: `#82A6A6`.
- Every individual glyph uses the same 240-unit-high reference canvas and baseline.

Use these SVGs as separate Photoshop layers over a copy of the original title photograph. The resulting Photoshop composite is a placement reference only. The production deck will continue to use the untouched photograph and independent SVG layers.
