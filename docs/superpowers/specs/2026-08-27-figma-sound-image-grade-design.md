# Figma Sound image-grade design

## Objective

Bring the megaphone and piano campaign photographs into a closer tonal family without regenerating, repainting, reframing, or adding texture to either image.

## Approved treatment

- Use the existing source pixels only.
- Piano: lower only the brightest glass and background values by a subtle amount. Preserve the present black point, skin tone, teal fabric, and midtone separation so the photograph remains light and airy rather than becoming contrasty.
- Megaphone: shift the cyan/teal balance slightly away from green and toward blue. Preserve skin tone, the light right wall, the original black point, and all photographic detail.
- Apply the same grade to each image's desktop and mobile-crop asset so the responsive deck does not change color between viewport sizes.
- Keep the current mobile crops and slide structure unchanged.

## Verification

- Confirm the deck references the newly graded desktop and mobile assets.
- Visually compare the four final assets for restrained highlights, matching blue-teal balance, clean texture, and unchanged composition.
- Run the branding-deck asset check, production build, and whitespace validation.
