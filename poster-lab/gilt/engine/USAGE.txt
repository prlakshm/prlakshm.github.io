GILT ENGINE: USAGE NOTE FOR CONCEPT AGENTS
==========================================
(poster-lab/gilt/engine; last calibrated on concept A, 2026-10-04)

Concept agents do NOT edit anything in engine/ or tools/. A concept is data:
it lives in concepts/<id>/ and every number below can be set from concept.json.
If you need behaviour the engine cannot express, report it; do not patch the engine.

---------------------------------------------------------------------------
1. ADD A CONCEPT
---------------------------------------------------------------------------
Folder: poster-lab/gilt/concepts/<id>/
  atlas_print.png  RGBA8, STRAIGHT alpha (not premultiplied), power of two
                   (1024x1024, 2048x1024 or 2048x512). RGB = printed colour, sRGB
                   (gold baked to look like photographed leaf under soft light;
                   watercolour ink for the printed parts). A = coverage.
                   Baked at 2 texels per CSS px. Keep crinkle periods >= 3.5 texels.
  atlas_fx.png     RGB8, lossless, same size. R = foil 0..1, G = pearl/satin 0..1,
                   B = height (0.08 paper .. ~0.59 foil plateau; the shoulder spills
                   ~2 CSS px past the coverage edge). A = 255.
  layout.json      { "atlas": {"w","h"},
                     "hero": "<piece id>" | {"desktop":[x,y], "mobile":[x,y]} (optional),
                     "pieces": [ {
                        "id", "rect": [x,y,w,h]   atlas px, incl. a 6-texel margin
                        "anchor": [ax,ay]          fraction of rect (default .5,.5)
                        "desktop": {"x","y" (band fractions, y down), "h" (rect height in
                                    BAND HEIGHTS), "rot" (rad), "flip" (bool)}
                        "mobile":  same, or null = hidden below the breakpoint
                        "z" draw order (low first), "keep" 0..1, "phase" 0..1,
                        "breathe" 0..1 (scales the swell tilt; default 1),
                        "tilt": [tx,ty] base tilt of the normal, rad (+x right, +y up)
                        "warp" 0..1 (FOIL_WARP only; default 1),
                        "warpAnchor" 0..1 (FOIL_WARP only; 1 = top pinned, bend grows
                                   down the piece, for strands hung from the top edge) } ] }
  under_d.png      RGBA8 band-space composition map, 512x100 (desktop)
  under_m.png      RGBA8, 256x124 (mobile). R = cloud reflection (pale),
                   G = willow reflection (cobalt; also turns brush VERTICAL if
                   water.WILLOW_VERT > 0), B = lavender shadow, A = sun path.
                   Write PNG (or webp with -exact): A is ~0 almost everywhere and any
                   premultiplying encoder/resizer wipes R,G,B. The engine uploads
                   them with premultiplication OFF.
  concept.json     { "name", "pitch", "lighting":{..}, "motion":{..}, "water":{..},
                     "flags":{..}, "coverage":[lo,hi], "layers":{..} (optional) }
                   Anything left out uses the engine default. Unknown keys are
                   ignored; wrongly-typed values fall back to the default and are
                   listed in the page's warnings (shown on the lab page).
                   Optional "layers": {"print","fx","under_d","under_m"} = other
                   filenames in the folder.

Coordinates everywhere: CSS px, x right, y DOWN, band 1440x279 desktop
(h = clamp(180, 0.194 w, 340)), 375x180 on phones; breakpoint 900 CSS px.
Never put foil, shoulder or shade in the top 3 device rows (clean top edge).

The concept A bake is a working template:
  scratchpad/redo/gilt/bake/  (pieces.py, layout_A.py, atlas.py, under.py,
  concept_A.py + concept_A_tuned.json, preview.py, measure.py; bake_A.sh runs it all)
pieces.py defaults now include a burnished stamped edge (env GILT_ROUND_TO=12,
GILT_SPLIT=0.4, GILT_BURN=1,10): the crinkle dies out over the round-over so the
rim reads as a glossy bevel. This is what moved the lit-rim check into range;
reuse it for any foil shape with an interior.

---------------------------------------------------------------------------
2. VIEW / TRY VALUES
---------------------------------------------------------------------------
Dev server already running (do not start/stop it):
  http://localhost:5173/poster-lab/gilt/index.html?c=<id>
    &t=<s>         frozen time (default 0)          &live   real clock + cursor
    &lamp=idle|off|hero|water|far|smallest|x,y     (x,y CSS px or fractions)
    &w=<css px>  &h=<css px>  &dpr=<n>  &arrive  &noHalf
    &debug=caught|hot|glow|height|near|coverage|normal|env
    &ab=RELIEF:1.6,key.c:[-0.2,0.2],water.SW:20,flags.SWELL_TILT:true
        (unqualified names are searched in lighting, motion, water, flags;
         arrays as [a,b]; a single number into an array fills every element;
         name[i]:v sets one element)
  window.__gilt: ready, frame(dt), at(t), setPointer(x,y), setLamp(mode),
    setDebug(name), stats(), pieces(), spots(), snapshot() (exact pixels, data URL),
    bench(n), measure(), loseContext().   Errors (incl. shader logs) -> window.__error.
  stats().scene.lamp.on is the scene's idle value; stats().lampOnRendered is what
  is drawn (0 with &lamp=off).

---------------------------------------------------------------------------
3. CAPTURE AND MEASURE
---------------------------------------------------------------------------
Full capture (~90-120 s; all plan 4.2 frames, perf, off-screen, reduced motion,
context loss, no-half, contact sheet, metrics.json):
  node poster-lab/gilt/tools/capture.cjs <id> [outDir] [--ab=...] \
       --ref=<scratchpad>/redo/gap
  -> <scratchpad>/redo/gilt/caps/<id>/ (cs.png, zooms.png, film.png, metrics.json ...)
Do not edit engine files while a capture runs (Vite reloads the page).

Fast loop (~5 s; rest, lamp-on-hero, masks, optional 8 s idle film, then the bake's
measure.py with every 4.3 check):
  python3 <scratchpad>/redo/gilt/int/qm.py <tag> "<ab string>" [--film] [--w=375] [--c=<id>]
  -> <scratchpad>/redo/gilt/int/q/<tag>/   (qm.py defaults to --c=A)
  python3 <scratchpad>/redo/gilt/int/breathe.py <tag>   per-piece idle swing (needs --film)
  python3 <scratchpad>/redo/gilt/int/z3.py out.png <tag> ...   hero 3x vs her crops
    (z3 crops at the A hero position; change cx,cy for your hero)
Or by hand:
  python3 <scratchpad>/redo/gilt/bake/measure.py --rest r.png --foil foil.png \
    --cov cov.png --lamp l.png --lamp-xy X,Y --idle f0.png ... --coverage lo,hi
  (foil = R and cov = G of a &debug=coverage snapshot)

Use the shared off-screen Chrome (scratchpad/lab/ws.txt), never the in-app browser.

---------------------------------------------------------------------------
4. FLAGS (concept.json "flags"; compiled in as #defines)
---------------------------------------------------------------------------
FOIL_WARP      (C) pieces bend sideways with a wave travelling down them; FA/FX are
               redrawn every frame, NEAR on paint ticks. Knobs: motion.WARP_AMP 1.25
               CSS px, WARP_LEN 140 CSS px, WARP_PERIOD 7.5 s; per piece "warp" and
               "warpAnchor" in layout.json. Gold position changes, so the plan's
               "gold moves <= 1.5 px" check applies.
SWELL_TILT     (B) adds the water swell's slope at each pixel to the foil normals
               (glitter path shimmers and travels). Knob: lighting.SWELL_AMP 0.06 rad.
INVERT_RELIEF  (D) the leaf sits low, the paint around it is raised impasto whose
               ridges follow the painted ground's value. Knobs: lighting.INV_PAINT 0.32
               (paint plateau), INV_K 0.5 (leaf depth), IMPASTO 0.35. Costs 18 texture
               reads in FINISH (budget 14): report it, it is a known overrun.
All three compile and render together (smoke-tested on A, 2026-10-04).

---------------------------------------------------------------------------
6. RULES THAT ARE EASY TO BREAK
---------------------------------------------------------------------------
- No green: ground CIELAB hue 115-190 with C* > 10 must stay <= 0.5% of the band.
  Teal-ish LIGHT/SUN colours drift into it once strokes jitter them; keep hue >= 210.
- Environment stays achromatic. Never put blue/teal into TINT or the studio: gold
  goes olive. Gold check: no foil px with L* < 70 at hue > 105.
- No drawn outline: edges come from emboss lighting only. If a ring reads dark,
  lower POOL / CONTACT before anything else; never bake a dark contour into the print.
- Light water (Pranavi's standing rule): lighter than the Monet overall.
- One metal: yellow gold.
- Copyright: nothing from Ann Nguyen's files in the repo; no live bubbbly loads
  (use the saved crops in scratchpad/redo/gap, anatomy/crops, foiltex/ref).
- Mobile: do not scale relief by draw size (mipmaps already soften it).
